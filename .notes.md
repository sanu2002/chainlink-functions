The core problem Chainlink Functions solves ??

“How do I let a smart contract trigger a private API request without exposing secrets, while keeping execution verifiable and decentralized?”

---
🙆🏾‍♂️use-secrets-threshold (🔐 MAX SECURITY)
    -> Secrets are sharded
    -> Stored across multiple DON nodes
    -> No single node knows the full secret

What we will gain ?
✅ Highest security
✅ Enterprise-grade
✅ Exchange-grade key safety

What you lose

❌ Setup complexity
❌ Harder debugging

When you need it

Custodial funds

Exchange API keys (Binance / Aster / OKX)

Anything that can move money

Mental model

“This is like splitting a private key across 10 HSMs.”

---
---
🙆🏾‍♂️ use-secrets-gist :- 
Secrets live in a private GitHub Gist

DON fetches it securely

Easier iteration

What you gain

✅ Very easy setup
✅ No local encryption tools
✅ Perfect for demos / PoCs

What you lose

❌ GitHub trust assumption
❌ Not ideal for production funds

When to use

Hackathons

Early-stage products

Read-only APIs

Mental model

“Secrets live in a locked vault on GitHub instead of your laptop.”

---

---
🙆🏾‍♂️use-secrets-url

What it unlocks

Secrets fetched from any HTTPS endpoint

Can integrate:

AWS Secrets Manager

GCP Secret Manager

HashiCorp Vault

Your own backend

What you gain

✅ Full control
✅ Key rotation
✅ Enterprise infra compatible

What you lose

❌ You must secure the endpoint
What you lose



When to use

Real products

Compliance

Exchange integrations

Mental model

“Chainlink DON asks your server for secrets, never your contract.”
---

---

🙆🏾‍♂️send-cbor
This is not about secrets — this is about protocol control.

What it unlocks

You manually encode the request

Full control over:

arguments

secrets

callbacks

gas usage

Why this exists

The default sendRequest() is a convenience wrapper.

CBOR lets you:

batch requests

reuse encoded payloads

build meta-oracles

forward requests

When you need it

Advanced workflows

Multi-hop oracles

Relayers

Protocol-level tooling

Mental model

“sendRequest is REST, sendCBOR is raw TCP.”
